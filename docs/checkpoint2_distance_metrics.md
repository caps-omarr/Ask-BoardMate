### 1. Mathematical Formulations & Metric Definitions

In vector space retrieval, similarity between a query vector $\mathbf{q} \in \mathbb{R}^d$ and a candidate document chunk vector $\mathbf{d} \in \mathbb{R}^d$ ($d = 384$ for `all-MiniLM-L6-v2`) is computed using three primary distance/similarity formulations:

#### A. Cosine Similarity ($\cos \theta$)
Measures the cosine of the angle between two dense vectors, capturing directional orientation irrespective of vector magnitude.

$$\text{Cosine Similarity}(\mathbf{q}, \mathbf{d}) = \frac{\mathbf{q} \cdot \mathbf{d}}{\|\mathbf{q}\|_2 \|\mathbf{d}\|_2} = \frac{\sum_{i=1}^{d} q_i d_i}{\sqrt{\sum_{i=1}^{d} q_i^2} \sqrt{\sum_{i=1}^{d} d_i^2}}$$

* **Cosine Distance:** $D_{\text{cosine}}(\mathbf{q}, \mathbf{d}) = 1 - \text{Cosine Similarity}(\mathbf{q}, \mathbf{d})$
* **Range:** $[-1.0, 1.0]$ for similarity ($0.0 \le D_{\text{cosine}} \le 2.0$).

#### B. Euclidean ($L_2$) Distance
Calculates the straight-line geometric distance between two vector endpoints in $d$-dimensional space.

$$D_{L2}(\mathbf{q}, \mathbf{d}) = \|\mathbf{q} - \mathbf{d}\|_2 = \sqrt{\sum_{i=1}^{d} (q_i - d_i)^2}$$

* **Range:** $[0.0, \infty)$. Smaller values indicate higher geometric proximity.

#### C. Dot Product / Inner Product (IP)
Calculates the scalar projection of vector $\mathbf{q}$ onto $\mathbf{d}$.

$$\text{Dot Product}(\mathbf{q}, \mathbf{d}) = \mathbf{q} \cdot \mathbf{d} = \sum_{i=1}^{d} q_i d_i$$

* **Unit-Norm Identity:** When embeddings are $L_2$-normalized ($\|\mathbf{q}\|_2 = \|\mathbf{d}\|_2 = 1.0$), Dot Product equals Cosine Similarity, and Euclidean distance directly relates via:
$$D_{L2}^2(\mathbf{q}, \mathbf{d}) = 2 - 2(\mathbf{q} \cdot \mathbf{d})$$

### 3. Metric Comparison & Defensible Recommendation

```
+-------------------------------------------------------------------------+
|                  DISTANCE METRIC EVALUATION MATRIX                      |
+-------------------------------------------------------------------------+
| Metric            | Length Sensitivity | Unit-Norm Identity | Recommended|
+-------------------+--------------------+--------------------+------------+
| Cosine Similarity | Invariant          | Yes (Direct)       | HIGHLY REC |
| Euclidean (L2)    | Sensitive          | Equiv when L2=1    | Acceptable |
| Dot Product (IP)  | Sensitive          | Identical if L2=1  | Fast (SIMD)|
+-------------------------------------------------------------------------+
```

#### Key Analytical Insights:
1. **Normalized Embedding Identity:** Because `all-MiniLM-L6-v2` outputs $L_2$-normalized vectors ($\|\mathbf{x}\|_2 = 1.0$), Cosine Similarity and Dot Product produce identical numeric scores.
2. **Ranking Equivalence:** All three metrics yielded 100% identical Top-5 candidate rankings across all test queries when embeddings are unit-normalized.

#### Defensible Architectural Recommendation:
We recommend **Cosine Similarity** (or $L_2$-normalized Dot Product in ChromaDB/HNSW vector indices) for E-BoardMate because:
* **Length Invariance:** Student search queries vary significantly in length (e.g., brief keywords like `"female dorm"` vs. long detailed paragraphs). Cosine similarity measures conceptual direction without penalty for text length variations.
* **Bounded Thresholding:** Cosine similarity scores strictly range between $-1.0$ and $+1.0$, allowing developers to set intuitive minimum similarity thresholds (e.g., `similarity >= 0.50`) for context filtering prior to LLM generation.
